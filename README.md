# 🧮 Simple Calculator in C++

A simple, menu-driven console calculator application written in C++.

## 📝 Description
This application performs standard arithmetic operations (addition, subtraction, multiplication, and division) based on user input. It features robust input validation (such as preventing division by zero) and allows users to perform multiple calculations in a single session.

## 🛠️ Key Concepts Applied
- **Functions:** Modular code structure using functions for each arithmetic operation.
- **Control Flow:** Utilizing `switch-case` statements for selecting operations.
- **Edge-Case Handling:** Safe checking against division by zero.
- **Looping:** `do-while` loop implementation to allow repeated usage until exited by the user.
- **Console I/O:** Reading numbers and character operators using standard `cin` and `cout`.
